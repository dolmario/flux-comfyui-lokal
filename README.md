# FLUX.2 with ComfyUI on AMD Strix Halo: your first local image

Create your own image with FLUX.2 dev in ComfyUI, without Nvidia. Tested on a GMKtec EVO-X2 (AMD Ryzen AI Max+ 395, Radeon 8060S, 64 GB shared memory) with ROCm on Windows.

| Language | Guide | Download |
|---|---|---|
| English | [EN/START.md](EN/START.md) | [BEGLEITPAKET-EN.zip](BEGLEITPAKET-EN.zip) |
| Deutsch | [DE/START.md](DE/START.md) | [BEGLEITPAKET-DE.zip](BEGLEITPAKET-DE.zip) |

1. Download the ZIP and extract it completely.
2. Open `START.md` and follow the steps.
3. Load the workflow `FLUX2-Q4-EVO.json` in ComfyUI, change the prompt, generate.

Model weights are not included; download them from the official sources linked in the guide. Results were measured on the EVO-X2 above; other hardware can behave differently. [SHA256 checksums](SHA256SUMS.txt)
